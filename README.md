# AI-плагин для STE Slicer

Проект для хакатона по созданию ИИ-ассистента STE Slicer.

Реализованы карта задачи, подключение LLM, MCP, уточнения, согласование плана,
инструменты STE Slicer и экспорт. Калибровки исключены.
Добавлен локальный дашборд подготовки: задачи, препятствия, задержки, токены API
и выгрузка CSV — [как пользоваться аналитикой](docs/analytics.md).
Проверка в настоящем приложении и результаты по моделям ещё не приняты:
[состояние и доказательства](docs/implementation-verification.md).

- `docs/` — задание и требования хакатона.
- `data/` — выданные примеры деталей: модели, изображения и технические задания.
- `plugin/` — исходный код плагина и инструкция по его установке и настройке.
- `results/` — результаты по каждой модели: проект 3MF, G-code и скриншоты переписки с чатботом.

Для Python-скриптов и тестов используется общая `.venv` в корне и `requirements.txt`.
Создание среды и команды запуска описаны в [README плагина](plugin/README.md#разработка-и-проверки).

Для установки или обновления плагина закройте STE Slicer и дважды щёлкните
**`install-plugin.cmd`** в корне репозитория. Он сам запустит PowerShell.
Окно останется открытым, чтобы можно было прочитать результат или ошибку.

Скрипт копирует плагин в `%APPDATA%\steslicer\7.10\plugins\AIAssistant`.
После успешной установки запустите STE Slicer.
