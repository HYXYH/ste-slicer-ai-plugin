# База знаний

Рабочие файлы устанавливаются в `AIAssistant/knowledge`. `rules.json` пока пуст.
`task_briefs.json` содержит точный извлечённый текст семи предоставленных DOCX,
относительный источник и SHA-256 XML. Это observation, а не reviewed-рецепты.
Автоматического обучения по опытам и сценария калибровок нет.

Пересоздание после изменения исходных описаний:

```powershell
.\.venv\Scripts\python.exe tools/import_task_briefs.py
```

`template.json` не участвует в поиске. Скопируйте его запись в массив
`rules.json`. Заполните источник, условия, запреты, необходимые факты,
изменения и пределы с единицами. Не меняйте статус на reviewed без проверки
специалиста. Укажите reviewed_by и reviewed_at.

Для каждой рекомендации специалист должен определить принтер, режим, сопло,
материал, нагрузки, среду, запреты, необходимые ответы, исходный профиль,
допустимые значения и единицы, подтверждающий источник, повод для калибровки
и ограничения. Данные каталога слайсера не подтверждают наличие катушки.

Условие: `{field,op,value}`. `eq` сравнивает значение; `in` проверяет
принадлежность заданному массиву; `gte/lte` сравнивают числовые величины
в заранее одинаковых единицах. `exists` с bool проверяет наличие ненулевого
значения. Отсутствующее или null значение для остальных операторов даёт unknown.
Существующие `false`, `0`, `""` не равны отсутствию. Приведения строк к числам нет.
Python и иные выражения из записей не выполняются.

Нарушенное applies_when исключает запись. Истинное excluded_when запрещает её.
Неизвестное условие сохраняет запись с missing_fields и applicability=unknown.
Доказательством рекомендации может служить только reviewed-запись с автором
проверки, датой и выполненными условиями. Противоречащие рекомендации дают
список conflicts. Пустая база или одни наблюдения возвращают KNOWLEDGE_GAP.

Автоматическая инженерная проверка рекомендаций ещё не подтверждена. В текущем
исполнителе критичное требование получает pass после явной ручной проверки
именно этого requirement_id. Описание другого требования не подходит.
